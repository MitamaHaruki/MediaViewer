### CPU・メモリ（各状態で20〜30秒の平均。CPU は全24スレッドに対する割合）

| 状態 | CPU | Private | 作業セット |

## 2. 長時間の使用（メモリ・ハンドル）

### 長時間再生

4K60 の動画をリピートで10分間再生し、30秒ごとに記録した。

| 項目 | 10分間の推移 |
|---|---|
| CPU | 0.75〜1.04%（増えない） |
| Private メモリ | 333〜349 MB で横ばい |
| ハンドル数 | 2057 → 1995（増えない） |
| GPU | 3D 5〜11%、動画デコード 27〜40%、専用メモリ 480 MB で一定 |

### 連続切り替え

画像・動画・音声が混在するフォルダで「次のファイル」「前のファイル」を UI オートメーションで押し続け、30回ごとに記録した（画面を操作する擬似入力は使っていない）。

- メモリ：600回切り替えても約 350〜420 MB で横ばい（切り替えのたびに上下するが、増え続けない）。GPU 専用メモリも一定。
- ハンドル数：**動画を開くたびに約 0.5 個ずつ増え続ける不具合を見つけ、修正した**（下記）。

### ハンドルが増え続ける不具合の調査と修正

1. ハンドルの種類別の数を調べる道具を作り、増えているのは Event だけと特定（画像だけの切り替えでは増えない）。
2. GC（ガベージコレクション）を強制した後でも増えるため、一時的なものではなく本当の漏れと判断。
3. 開発用の調査モード（Debug ビルドのみ、`LeakProbe`）で部品ごとに繰り返し試し、次を確認。
   - FFmpegInteropX の読み込み、再生制御クラス、再生位置のタイマー：増えない
   - メイン画面で同じファイルを繰り返し開く、音声を切り替える：増えない
   - 動画を切り替える：増える。ハードウェアデコードや映像フレームの受け取りを止めても増えるが、**回転情報の読み取りを止めると増えない**
4. 回転情報は Windows のプロパティシステム（StorageFile と GetVideoPropertiesAsync）で読んでいた。IPropertyStore を直接使って確実に解放する方式でも増えたため、Windows のプロパティハンドラー自体が MP4 を読むたびにハンドルを残すと判断。
5. MP4・MOV の映像トラックの表示行列（tkhd）をファイルから直接読む方式（`Mp4Orientation`）に置き換えた。手元の動画10本（回転 0・90・180・270 と MKV・WebM・MP3）で Windows のプロパティシステムと同じ値になることを確認し、単体テスト9件を追加。
6. 修正後は、回転付きを含む動画と音声を150回開いてもハンドル数は 1862 → 1867 で横ばい（修正前は同じ条件で 1967 → 2019）。

7. 配布版と同じ設定で 600 回の連続切り替えをやり直し、ハンドル数は 2171〜2211 で横ばい（Event は 570 回で +20。修正前は 330 回で +103）、メモリも 350〜420 MB で横ばいになったことを確認。

| 600回の連続切り替え | 修正前 | 修正後 |
|---|---|---|
| ハンドル数（1周目 → 20周目） | 2112 → 2320（増え続ける） | 2171 → 2196（横ばい） |
| Private メモリ | 346〜396 MB | 351〜423 MB |
| スレッド数 | — | 135〜143 |

途中で、ファイルごとに MediaPlayer を作り直す方式も試したが、破棄した MediaPlayer の後片付けが追いつかず、メモリ・スレッド・GPU メモリがかえって増えたため採用しなかった。

## 6. 測定の方法（再現用）

- 測定用の記録：環境変数 `MEDIAVIEWER_TRACE_PERF=1` で、起動時間・ファイルを開く時間・描画1回の時間・30回ごとの GC 後のハンドル数とメモリをログへ書く（通常はログを書かない）。
- 入力の調査：`MEDIAVIEWER_TRACE_INPUT=1` で、画面に届いた入力と、ドラッグでの移動を記録する。
- 部品ごとの漏れの調査：Debug ビルドで `MEDIAVIEWER_LEAK_PROBE`（source、player-reuse、player-new、timer、controller、window）と `MEDIAVIEWER_LEAK_PROBE_FILE`（`;` 区切り）、`MEDIAVIEWER_LEAK_PROBE_COUNT` を指定して起動する。
- 測定中は `MEDIAVIEWER_SETTINGS_PATH` で試験用の設定ファイル（ミュート）を使い、利用者の設定を変えない。

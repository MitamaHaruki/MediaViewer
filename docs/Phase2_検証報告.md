# Phase 2 検証報告（基本ビューワーと色管理の仕上げ）

- 実施日：2026-10-20
- 対象：開発指示書 §16 Phase 2、§5（フォトビューワーと色管理）、§15（エラー処理）
- 検証環境：Phase 1 と同じ（Windows 11、Core i9-12900F、GeForce RTX 4060 Ti、SDRモニター3台）

## 1. 実施内容

| 項目 | 内容 |
|---|---|
| GPU デバイス消失からの復旧 | 描画・Present の失敗からデバイス消失を判定し、描画と再生を作り直して表示中のファイルを開き直す。動画・音声は再生位置と再生中かどうかを引き継ぐ。開発用に Ctrl+Shift+Alt+D（Debug ビルドのみ）で消失を模擬できる |
| CMYK 画像 | 埋め込みの CMYK ICC で、作業用の広色域 RGB（BT.2020・ガンマ2.2・16bit）へ変換してから通常の色管理に通す。ICC がない場合は Windows 標準の SWOP プロファイルで変換し、その旨を画面に通知する |
| グレーICC 付き画像 | グレーの階調特性（kTRC）を同じ階調の RGB プロファイルに写し、同じ描画経路で表示する |
| PNG の色指定 | 優先順位 cICP → iCCP → sRGB → gAMA/cHRM（PNG 第3版）。cICP は sRGB・BT.2020・Display P3 の原色と sRGB・線形・ガンマ2.2・BT.709 系の伝達特性に対応。gAMA 1/2.2 のみの指定は sRGB として扱う |
| HDR 画像（PQ） | PNG の cICP（BT.2020・PQ）を HDR として読み、表示先に合わせてトーンマップする（HDR 表示ではモニターの最大輝度まで、SDR 表示では SDR の白まで）。cLLi（最大輝度）があれば使う |
| EXIF の色空間 | ICC なしで ColorSpace=未校正、互換性インデックス R03 の JPEG（カメラの Adobe RGB モード）を Adobe RGB として扱う |
| 巨大画像の省メモリ化 | 画像は帯状（約4MBずつ）にデコードして GPU へ転送し、帯ごとに中断できるようにした。画像を切り替えたら、ドライバーが保持している解放済みの GPU メモリを返させる |

## 2. 見つかった不具合と修正

| 不具合 | 影響 | 修正 |
|---|---|---|
| 16bit 画像の階調がずれる | Phase 1 から存在。16bit PNG/TIFF 等で、WIC が整数→浮動小数の変換時に sRGB ガンマを外していたため、ICC 付き16bit画像の色が暗く・濃くなっていた | 16bit は整数（R16G16B16A16_UNORM）のまま GPU へ転送する |
| 画像・動画を切り替えるたびに GPU メモリが増える | Phase 1 から存在。8000×6000 の画像を切り替えるたびに約190MB、動画は1フレーム分ずつ増え続けた | 色変換エフェクトの出力参照を解放していなかったのが原因。すべて解放するよう修正し、切替時に解放済みメモリを返させる |

## 3. テスト

単体テスト 54 件（Phase 1 から 20 件追加）がすべて成功。追加分は次のとおり。

- グレーICC（kTRC ガンマ1.8）が期待どおりの明るさの無彩色になる
- CMYK（埋め込み ICC あり／なし）の白・K100・C100・M100 の色が妥当
- PNG の cICP（Display P3）、cICP が iCCP より優先、対応外の cICP（HLG）は注記付きで sRGB
- PNG の gAMA のみ（1/1.8 はそのガンマ、1/2.2 は sRGB）、cHRM＋gAMA（広色域）、sRGB チャンク
- PQ の HDR PNG：HDR 表示（最大600nit）で 100nit → scRGB 1.25、1000nit → 7.50 に収まる。SDR 表示では SDR の白以内
- EXIF：未校正＋R03 は Adobe RGB、R98 は sRGB のまま、向き（1・3・6・8）と縦横の入れ替え
- 壊れたメタデータで例外にならない、ICC の para 型カーブの解釈

## 5. 既知の制約・未確認事項

| 項目 | 内容 |
|---|---|
| HDR 画像の対応範囲 | PNG の PQ（BT.2020）のみ。HLG、BT.2020 以外の PQ、JPEG XR／AVIF／HEIC の HDR は未対応（sRGB として表示し、対応外の cICP は通知する） |
| 浮動小数の画像（float TIFF 等） | 線形の値として正しく扱う処理は未実装 |
| アルファ付き CMYK | 色変換でアルファが失われる可能性がある |
| 帯状転送の効果 | PNG は WIC のデコーダーが内部で全体を保持するため、読込み中のピークは減らない（読込み後は解放される） |
| タッチ・HDR／ACM モニター・ICC 設定済みモニターでの実表示 | Phase 1 から引き続き実機確認待ち |

## 2. 今回の実施内容

| 項目 | 内容 |
|---|---|
| 設定の保存（§12） | 前後移動の対象、音量、ミュート、シーク幅、ウィンドウの位置・大きさ・最大化、自動更新の設定（自動確認・自動ダウンロード・適用タイミング・最終確認時刻）を `%LocalAppData%\MediaViewer\settings.json` に保存。色管理は常に有効（設定なし）、フルスクリーンは保存せず常に通常表示で起動 |
| 壊れた設定への備え | 壊れたファイルは `settings.json.broken-日時` に退避して既定値で起動。範囲外の値は安全な値に直す。知らない値（新しい版が追加した選択肢など）はその項目だけ既定値にする |
| 版の互換性 | スキーマ番号を持つ。新しい版が書いた知らない項目は、古い版で保存しても消さずに残す（更新・ロールバックで設定を失わない） |
| 多重起動への対応 | 保存はプロセス間で排他し、最新の内容を読み直して変更した項目だけを反映する。一時ファイルに書いてから置き換える。2つ目以降のウィンドウは既存のウィンドウと重ならないよう 32px ずらす。音量は自分のウィンドウで変更した場合だけ終了時に書く |
| ウィンドウ位置の復元 | 終了時の通常位置・大きさと最大化状態を保存。フルスクリーン中に終了した場合はその前の状態を保存。モニターの構成が変わって画面外になる場合は、最も近いモニターの作業領域に収める |
| 一般設定画面 | 設定 → 一般設定 で、シーク幅（5／10／30秒）を選べる。設定ファイルの場所を開ける |
| 音量の初期値 | 80%（仕様 §12「常識的な初期音量」） |
| 自動テスト用 | 環境変数 `MEDIAVIEWER_SETTINGS_PATH` で設定ファイルの場所を変えられる（利用者の設定を書き換えずに検証するため） |

## 3. テスト

単体テスト 61 件（7 件追加）がすべて成功。

- 初期値が仕様どおり、保存した内容を読み戻せる、一時ファイルが残らない
- 壊れたファイルの退避と復旧、範囲外の値の補正
- 2つのプロセスがそれぞれ別の項目を変えても互いに消さない、16 並列で保存しても壊れない
- 新しい版の知らない項目を保存で消さない

実際のアプリでの確認：

- 位置・大きさ・音量・ミュート・フィルターを変えて終了 → 次回起動で復元される
- 最大化して終了 → 次回は最大化で起動し、通常時の位置・大きさも保持される
- 2つ目のウィンドウは 32px ずれて開く
- ウィンドウ B で変えた設定（シーク幅・音量）が、後からウィンドウ A を閉じても消えない
- ミュートした直後に終了しても保存される
- 壊れた設定ファイルでも起動し、ファイルは退避される
